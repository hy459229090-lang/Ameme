# R1 多端官方能力证据矩阵

> 文档状态：官方桌面研究完成；仅 Windows 低风险能力有本机探针证据\
> 更新日期：2026-07-13\
> 证据等级：`O` 官方文档，`L` 本地/设备实测，`S` 官方导出样本，`U` 用户行为证据。进入 Prototype 的主来源应在 Gate 2 前补到 `O+L` 或 `O+S`。

## 1. 跨端结论

1. 最稳定的低权限路径不是同一种 API，而是同一种原则：用户选范围、系统提供选择器/授权、端侧先处理、只传最小结果。
2. Desktop 适合连续的元数据和选定目录/项目；Mobile 适合系统建议、Picker、Share 和分类型健康授权；Communication 适合组织安装后的事件流；Agent 适合受 purpose 限制的读取/写回。
3. 截屏、录音、通知、Accessibility、全聊天和健康/财务不属于普通“连接器权限”，必须单独做高风险能力评审。
4. 数据可获得不等于可长期存储、可训练模型或可跨空间复用。Connector 必须把平台权限、用户许可、组织策略和 Ameme 用途同时写入 lineage。

## 2. 证据矩阵

| 端/来源 | 官方路径与实际边界 | 证据 | 当前判定 | Prototype 使用条件 |
|---|---|---|---|---|
| Windows 前台应用/UIA | Win32/UI Automation 可获得窗口与部分控件结构；应用覆盖差异大 | `O+L` | 部分验证 | 仅元数据、标题端侧分类、应用排除；不宣称统一读取正文 |
| Windows 文件事件 | 选定目录可走 .NET FileSystemWatcher；探针 v0.2 修复事件队列竞态后，create/change/rename/delete 连续 3 次稳定捕获 | `O+L` | 低风险能力已验证 | 只监听用户选择目录；真实样机继续测噪声、丢事件和恢复 |
| Windows 屏幕 | Windows.Graphics.Capture 使用安全系统 Picker，系统为捕获对象显示黄色边框；本机探针为 `RuntimeException` | `O+L失败` | 阻塞 | 不进入首个 Prototype；先定位运行时和授权交互 |
| macOS 文件 | App Sandbox 可通过 Open/Save Panel 获得用户选择文件/目录，持久访问需 security-scoped bookmark；FSEvents 提供目录树变更 | `O` | 官方可行 | 需要 macOS 设备 Spike；只读取选择范围 |
| macOS 屏幕 | ScreenCaptureKit 推荐系统内容选择器，并要求屏幕录制权限 | `O` | 高权限可行 | 不作默认；必须可见状态和单次/选窗口授权 |
| Chrome 当前页 | `activeTab` 只在用户触发后临时授权；合成 Spike 证明触发前 URL/标题不可见、触发后可读当前页、跨 origin 后撤回 | `O+L` | 低权限闭环已验证 | 可进入 Browser Basic；继续验证 PDF、登录页、内置页、排除和商店声明 |
| iOS 生活事件 | Journaling Suggestions 在系统进程显示候选；用户选择后应用只得到所选建议的高层信息，需要 entitlement | `O` | 强候选 | 需要真机、地区/版本/数据类型覆盖测试 |
| iOS 照片/文件/分享 | 系统 Picker、Share Extension 和用户选择路径适合显式导入 | `O` | 可行 | 真机验证导入后的权限生命周期与删除 |
| iOS HealthKit | 按数据类型分别授权；用户可在系统外部修改权限和删除数据，应用必须响应 | `O` | 高敏可行 | 独立 Health 空间；不进入首个通用 Prototype |
| Android Photo Picker | 系统只把用户选择的图片/视频授权给应用，不需整个媒体库权限；不可用时可退化为 `ACTION_OPEN_DOCUMENT` | `O` | 强候选 | 真机覆盖主流厂商、云相册和权限持久性 |
| Android Health Connect | 在用户许可后提供结构化健康数据、增删同步和后台读取；Google Fit API 支持到 2026 年底并建议迁移 | `O` | 高敏可行 | 独立 Health 空间；先验证发布政策和最小数据类型 |
| Android 通知 | NotificationListenerService 能收到通知发布/移除；工作资料可能被系统/管理员阻断 | `O` | 高风险、非跨端 | 不作为核心来源；若研究需独立显著披露和政策评审 |
| Android Accessibility | 技术上能读取/操作界面，但 Play 要求单独披露、同意和声明；非辅助工具的自主操作受到严格限制 | `O` | 不推荐 | 不用于首个版本的通用采集 |
| Android 后台任务 | 系统和厂商会限制后台作业、服务、网络与资源消耗，前台服务也持续收紧 | `O` | 不能保证持续无感 | 使用系统任务 API；设备矩阵实测电量、延迟和恢复 |
| Slack | Events API 按 OAuth scopes 和安装者/机器人可见范围推送；不是工作区全量镜像 | `O` | 企业后续 | 只接入明确 workspace/channel；保留卸载、撤权和删除事件 |
| Microsoft Teams | 委托 `Chat.Read` 可代表登录用户读一对一/群聊；应用级 `Chat.Read.All` 需要管理员同意 | `O` | 企业/个人路径不同 | 先选账户类型；禁止把 delegated 与 tenant-wide 混为一谈 |
| 飞书 | Bot 单聊、@消息和群全量消息是不同权限；群全量属于敏感权限，推送可能重复需 message_id 幂等 | `O` | 企业后续 | 首先验证 @Bot/用户主动转发，不从全群历史开始 |
| 企业微信 | 会话内容存档面向组织合规能力，不是普通个人 OAuth | 官方入口待可复核 | 待验证 | 未取得企业管理员和官方样本前不得进入 Prototype |
| 微信个人聊天 | 未找到适合普通第三方产品的官方全量读取接口 | 待验证 | 否决全量接入 | 只研究用户转发、截图或其主动导出的文件 |
| Gmail/Outlook 邮件 | Gmail 广泛只读 scope 属 restricted，需 OAuth 验证；Graph `Mail.ReadBasic` 不含正文/附件，`Mail.Read` 才能读正文 | `O` | 可行但高敏 | 先做用户选择标签/文件夹/时间段；优先基础字段和导入 |
| ChatGPT 导出 | 个人 Free/Plus/Pro 和部分 Edu 可导出 ZIP；Business/Enterprise 设置内导出不可用，生成可达 7 天 | `O` | 批量导入 | 适合一次性导入，不适合实时 Connector |
| Claude 导出 | 个人 Free/Pro/Max 可导出会话；Team/Enterprise 由 Primary Owner 导出；个人导出不能导入另一账户 | `O` | 批量导入 | 适合用户主动导入，不承诺持续同步 |
| Steam | Web API 有公开与受保护方法；很多接口需要 key，publisher 接口与个人路径不同 | `O` | 单平台候选 | 用公开资料/用户授权样本验证可见性，不保存凭证到客户端日志 |
| MCP | 标准化 Resources/Prompts/Tools；规范要求用户明确理解和同意数据访问、工具调用和外传 | `O` | 使用端，不是采集端 | 每次请求声明 purpose、spaces、time range、types，返回最小 ContextPack |

## 3. 首轮允许与禁止

### 允许进入低风险 Spike

- Windows 前台应用元数据与应用排除。
- 用户选择的项目目录、文件事件和 Git 元数据；继续测真实噪声与恢复。
- Chrome `activeTab` 一键 Capture；继续补特殊页面和打包扩展验证。
- iOS Journaling Suggestions 真机能力验证。
- iOS/Android 分享、照片选择和文件导入。
- ChatGPT/Claude 用户主动导出文件的离线解析。
- MCP 最小只读 ContextPack 契约设计。

### 暂不进入首个 Prototype 默认路径

- 连续屏幕/系统音频/麦克风捕获。
- Android 通知、UsageStats 或 Accessibility 全量读取。
- Slack/Teams/飞书/企业微信全量历史。
- 微信个人聊天非官方抓取。
- Health、Finance 与 Work 的自动交叉分析。
- 任何第三方 Agent 的数据库直连。

## 5. 尚缺的实测

1. Chrome `activeTab` 在普通页面已通过合成实测；仍缺登录页、PDF、浏览器内置页、排除域名和商店包结果。
2. iOS Journaling Suggestions 的设备、系统版本、地区和候选类型覆盖。
3. Android Photo Picker/Share 在主流国产 ROM 的后台恢复和 URI 生命周期。
4. Windows 文件事件竞态已修复；仍需定位屏幕 API `RuntimeException`。
5. ChatGPT/Claude 实际导出 Schema、附件、删除会话和增量导入行为。
6. Slack/Teams/飞书的数据删除、撤权、保留及 AI 处理政策。
