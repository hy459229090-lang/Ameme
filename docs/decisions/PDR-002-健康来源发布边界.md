# PDR-002：健康来源进入首个公开 MVP

- 状态：accepted（选择 A）
- 日期：2026-07-14
- 决策人：产品负责人
- 影响 Gate：Gate 3–6
- 替代/被替代：替代原“仅封闭测试、公开 flag off”决议

## 已接受决议

健康/身体与活动来源进入首个公开版本，覆盖活动、锻炼、睡眠、恢复和正念/主观状态五类入口。系统健康数据只读、逐类授权、本地优先；用户拒绝、撤销、锁定、无数据和未同步必须分别表达。

## 公开发布硬门

- 健康是公开 MVP 的目标能力，也因此成为发布阻断项：HealthKit/Health Connect 用途、商店申报、隐私披露、真机语义和删除测试未通过时，不得发布一个暗中移除健康却仍称完整 MVP 的版本。
- 每类必须有直接的“记录一天”用途；不做诊断、治疗建议、广告定向或健康风险评分。
- Restricted 健康正文默认不进入第三方模型或 Agent 自动上下文；需要独立、具体授权。
- 健康强度不能提高其他事件事实置信度，也不能被当成无活动/缺席的证明。

## 回滚

若平台/商店否决健康用途，必须回到产品负责人选择：延期整个公开 MVP，或正式调整公开范围；不能由 release flag 静默绕过本决策。

## 待验证项

HEALTH-01、双端真机、商店申报/预审、用户理解、后台/锁屏/撤权、五类最小字段、价值增量和删除证明。
