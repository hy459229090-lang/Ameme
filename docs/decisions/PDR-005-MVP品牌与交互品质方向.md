# PDR-005：MVP 品牌与交互品质方向

- 状态：accepted
- 日期：2026-07-14
- 决策人：产品负责人
- 影响 Gate：Gate 2–6
- 替代/被替代：补充 `产品体验风格与演进策略.md`

## 决议

Ameme MVP 的品牌关键词固定为：**简洁、高效、安静、可信、流畅**。以 ChatGPT 移动端的内容优先、单一主输入、能力渐进展开和低干扰反馈作为交互品质参考，但不复制 OpenAI 的名称、图标、布局细节或品牌识别。

## 可执行规则

1. `今天` 始终是唯一默认主页，不增加底部多 Tab 导航。
2. 页面主要面积留给事件内容；来源、设置、同步和 Agent 管理通过二级页面渐进展开。
3. Today 只保留一个悬浮“记录”主按钮；点击后使用平台原生 Sheet 展开文字、语音、照片和导入。首页不常驻输入框，也不平铺四个大按钮。
4. 使用系统字体、系统导航、系统 Sheet、系统搜索和平台可访问性；自定义只用于事件语义和 Ameme 强调色。
5. 浅色以系统背景/表面为主，MVP 强调色为 `Memory Teal #0D6B5B`；深色强调色为 `#72D6B5`。正文仍使用系统语义色，不用强调色承载长文本。
6. 不把每条事件做成厚重卡片；默认使用时间分组、留白、轻分隔和必要的媒体容器。
7. 用户动作先本地反馈，AI、同步、转写和索引状态在原位置渐进更新，不用全屏等待。
8. 动效只解释层级和状态变化，优先系统动画；遵守 Reduce Motion，不以动画掩盖等待。

## 性能品质门

- 触控视觉反馈在 100 ms 内出现。
- Today 冷启动首个可滚动帧 P95 ≤ 1,200 ms，热启动 P95 ≤ 500 ms。
- 文字/manifest 本地保存确认 P95 ≤ 300 ms。
- 本地搜索键入不阻塞主线程，100k Event 首屏 P95 ≤ 700 ms。
- M/H 日流慢帧比例 < 5%；任何同步/AI 任务不得阻塞滚动和输入。
- Crash-free sessions 候选门 ≥ 99.5%；任一已确认保存后丢失为阻断项。

数值是研发验收预算，不是当前已测结果；MOB/DB Spike 负责给出真机证据。
