## 跨端 UX 与架构审计

### 已关闭发现

- `P0` 配对 HMAC 表示不一致：Android/Host 使用 QR 中的 base64url 文本字节，iOS 曾使用解码后的 32 字节。现由 `AgentPairingEnvelope.channelSecret` 统一生产连接和 Smoke；新增单测、静态契约和真实跨端传输防回归。
- `P1` Android 大字号首屏主操作不可见：CTA 从滚动末端移到 `Scaffold.bottomBar`，1.3× 字号与较小可视高度下持续可操作。
- `P1` Android 动态列表 UI 测试误把未组合节点当作不存在：测试改用 `settings-list.performScrollToNode`，并以连接卡片消失判断断开完成。
- `P1` iOS Simulator 无法安装：`AmemeShared` 是静态 framework，App/Extension 现在只链接而不嵌入无 `Info.plist` 的静态产物；XcodeGen spec 与生成工程同时受门禁。
- `P1` iOS 辅助功能超大字体下时间轴横向布局被挤碎：记录卡在 accessibility size 改为纵向结构，时间、状态、标题、详情与来源按阅读顺序独占可用宽度；底部“记录”改用 `safeAreaInset`，不再覆盖列表内容。
- `P1` iOS 单项 `Menu` 在 XCUITest/辅助功能字号下存在但不可点击：Today/Search 设置入口改为直接 44×44 pt `Button`，日期按钮也补齐同等触控目标。
- `P2` 跨时区合成事件可能落到前一天：iOS 与 Host smoke 使用当前本地 offset 的 ISO 8601 时间，China midnight 回归可见。

### 当前视觉/交互判断

- Android Onboarding、真实 Today、Mock Today 在 1.3× 字号下没有主操作裁切、横向溢出或不可辨认的 Mock/真实状态。
- iOS 深色 + 辅助功能超大字体下，空态、Mock Today、Search 和横屏 Search 均有当前运行截图；时间轴记录卡按纵向重排，底部操作不遮挡内容。
- 原生平台设计差异被保留：iOS 使用 SwiftUI/System Sheets，Android 使用 Compose Material 3；共同语义为单一“记录”入口、Today 日流、Search、状态标签、来源/权限说明和显式演示边界，不追求像素相同。
- 最终截图未发现新的 P0/P1；两端核心操作、真实/Mock 边界和恢复文案均可辨认。

## 失败与限制

| Severity | 保留项 | 影响 | 发布动作 |
|---|---|---|---|
| Release blocker | iOS/Android 物理设备未连接 | 不能证明真实硬件性能、相机、后台、OEM 来源与权限生命周期 | 至少 1 台 iPhone/iPad + 1 台 Android 14+ OEM 设备复验 |
| Release blocker | 真实 VoiceOver/TalkBack 尚未人工读屏 | 自动化语义不能证明朗读顺序、焦点恢复和开关控制 | 发布负责人按设备清单人工验收 |
| Release blocker | iOS signing/App Group provisioning/Share Sheet、商店材料未执行 | 不能生成可分发包或声明商店就绪 | 配置签名、TestFlight/Internal testing、商店隐私申报 |
| Product blocker | 正式用户证据与生产模型/账户设备服务未闭环 | 不能声明市场价值、生产 AI 质量或账户同步 | 保持 Gate 1 / public release `hold` |
| Known boundary | AVD 通过 ADB forward；不是物理 LAN | 只能证明协议、TLS、Grant 与真实 App 数据路径 | 真机同网恶意 peer、撤销、过期、重连复验 |

## 隐私与证据处理

- 只使用 synthetic/固定 Mock；没有 Restricted 或真实参与者数据。
- 配对 secret 只在短时进程/设备缓存中使用，Smoke `finally` 清除 envelope、forward、Host、临时目录和密钥 bytearray；输出不打印正文或密钥。
- 本机截图保存在仓库外 `outputs/ameme-mobile-audit-20260726/`，不进入 Git；CI XCTest/设备报告作为 14 天 artifact。
- App icon 使用内置 ImageGen 生成：抽象连续丝带构成小写 “a”，配时间线圆点、青绿色与米白色、无文字。原始生成文件为 `/Users/riche/.codex/generated_images/019f9ae1-ef48-7090-ac89-7aae46b16057/call_e12CFwUZodHJoTPiQv9E229d.png`；项目资产为 `apps/ios/Ameme/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` 和 Android `mipmap-*/ic_launcher.png`。
