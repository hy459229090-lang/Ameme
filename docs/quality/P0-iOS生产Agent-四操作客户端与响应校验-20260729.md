# P0 iOS 生产 Agent 四操作客户端与响应校验

## 结论

iOS 的生产 `AgentLocalNodeNetworkClient` 已从只生成 `create_event` 请求、向调用方返回原始
application JSON，推进为冻结 `ameme.agent-local-node.v1` 四项 Android 生产 operation 的
fail-closed 客户端：

- `create_event`、`append_revision`、exact `undo_capture` 与 bounded `visible_events` 都有
  canonical builder、最小 scope 授权、握手 operation 协商检查和 typed result。
- 每个成功响应都先绑定 request ID，再验证六字段 application envelope、canonical bytes、
  `result_digest`、operation-specific exact shape、类型、数量和内容长度。畸形响应会销毁 session。
- 远端错误只接受冻结 code 与 retryability 配对；`NOT_VISIBLE` 等错误不携带目标身份或存在性
  细节。合法远端错误不被误判为 framing 攻击。
- `visible_events` 只允许 Event、query≤1,000、limit≤100、title/description≤240/1,000，
  拒绝重复 Event、反向时间区间和 scope 扩张；不增加通用 `get_event` 或策略写入。
- `undo_capture` 继续传递由原 capture idempotency slot 派生的 opaque token；Event 撤销要求
  object ID 与 Event 相同，Revision 撤销必须返回 exact compensation revision。
- 低层 raw application exchange 已改为私有，四个公开生产 exchange 不接受调用方伪造的授权时间，
  只能用当前时间执行 Grant 检查。

普通用户 QR 连接仍使用 event-only `AgentAccessGrantPolicy.default`，设置页仍只显示“写入结构化
工作记录”。本轮没有静默增加读取、Revision 或撤销授权；只有调用方提供明确包含
event/revision 的 Grant，且服务端握手宣告对应 operation 时，新 API 才能使用。

## 失败与证据限制

- 本切片实现、编译、Smoke 和静态门没有出现新的首次失败。
- 当前机器仍只有 Command Line Tools；既有 `swift test` 首次失败
  `no such module 'XCTest'` 未被改写为通过。新增 XCTest 仅完成源码 parse，等待完整 Xcode。
- 代码审计发现公开 raw exchange 与可由调用方传入的授权时间会削弱客户端本地 fail-closed
  边界；本轮已将 raw exchange 私有化，并让四个生产 exchange 固定使用当前时间。82 项静态门
  与网络 Smoke 在修复后重新通过。
- AVD 网络执行使用 ADB forward 与合成 expanded Grant，只证明当前 Swift/Android 生产实现的
  模拟器纵向兼容；真实 Host/ContextPack、后台、物理 LAN 与跨设备撤销传播仍未证明。

## 未关闭 Gate

- 普通用户若要授予读取、Revision 或撤销，必须先有与展示文案一致的独立确认流程；本轮故意
  保持 QR 默认 event-only。
- 完整 Xcode 的 XCTest/XCUITest、iOS Simulator/真机 Network.framework 与 Keychain、
  Android/iOS 物理 LAN、进程终止/重连和真实读屏仍为 `hold`。
- 共享账户 Grant registry、撤销传播、真实第三方宿主、生产 ContextPack、签名和发布仍为
  外部或后续生产 Gate。
- `get_event`、`set_policy_blocked`、长期 Memory confirmation、Raw/source/locator 读取继续关闭。

## 判定

`P0-IOS-AGENT-LOCAL-NODE-CLIENT-06` 关闭了仓库内 iOS 客户端“冻结 v1 已协商但无法构建三项
生产请求、成功响应没有 result digest/严格形状校验”的空白，结论为 `conditional_pass`。
不得将本报告扩写成普通用户已授权读取/撤销、共享 Grant、真实 Host/ContextPack、物理设备、
物理 LAN 或封闭 Beta 已通过。
