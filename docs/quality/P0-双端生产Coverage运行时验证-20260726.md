# P0 双端生产 Coverage 运行时验证

## 结论

Android 与 iOS 的生产模块现已具备同一组 Coverage v1 wire value、六项当前 Mobile 来源能力、保守 `CoverageCompiler` 和来源拒权/失败/不可用状态工厂。该切片可以把来源异常编译为 `partial` observation 与 `source_status_only` gap，并保证这些状态没有来源对象、证据字段或 `EventHint`，因此不能意外创建 Event。

本 Verdict 只覆盖当时的纯领域运行时和本地构建/测试，不覆盖 UI 接线、持久化、生产 Event/Revision/DayLedger 写入、删除传播、生产备份恢复、物理设备、真实用户或发布。后续持久化与显式 Event 接线切片见 `P0-双端Coverage持久化与显式Event接线验证-20260726.md`；六项能力的 `real_device`、`real_user`、`recovery`、`lineage` 和 `cascade_delete` 仍不能被理解成已通过声明。
