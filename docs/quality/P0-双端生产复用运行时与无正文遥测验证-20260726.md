# P0 双端生产复用运行时与无正文遥测验证

## 结论

Android 与 iOS 生产本地存储现已暴露统一的四类复用运行时：

1. `historical_search`：显式关键词或日期范围内的历史查找；
2. `project_resume`：必须由用户提供显式关键词。当前没有 Project 实体，不推断项目成员关系；
3. `pre_meeting_context`：必须由用户提供关键词或选择日期，不推断参会者、联系人或议程；
4. `decision_commitment_recall`：只复用当前有效的决定/承诺长期 Memory 与决定 Event，不使用候选、过期、失效或 Restricted 对象。

返回的 `ReuseContext` 只在内存中携带 exact Event/Memory ID、revision 和 Memory→Event lineage，15 分钟后失效。Android 在同一 SQLCipher read transaction、iOS 在同一 `MainActor` 同步调用中完成 revision/validity/删除/Restricted 复核和正文解析，关闭“复核后、展示前”被修订的窗口；上游修订、删除、失效或超时都会缩小上下文，不能静默从新内容重建旧上下文。

Android 与 iOS 的生产 Search 页面现在都只展示一个扁平“把记忆用起来”入口，再由平台原生选择器提供“历史找回、继续项目、准备会面、决定与承诺”四种意图；项目/会面继续要求用户输入关键词或选择日期。结果页可打开 exact source Event，并记录有帮助、没帮助、记错了、有遗漏或已过期；反馈提示明确不记录正文、query 或原始对象 ID。iOS 使用原生 `confirmationDialog` 与结果 Sheet；Android 使用 Material 3 `AlertDialog`，Search 内容统一进入一个 `LazyColumn`，避免小屏/大字号空态下入口不可达。固定 Mock 的演示模式不会生成生产复用记录。

持久遥测与上下文彻底分离。SQLCipher/AES-GCM 中只保存随机 attempt ID、intent、`complete/partial/empty` 本机范围、结果数量桶、以 attempt ID 加盐的 SHA-256 Event/Memory/lineage 摘要、策略排除码、结果、用户动作和时间。它不保存 query、Prompt、标题、正文、用户原话、SourceLocator、路径、原始 Event/Memory/lineage ID、联系人或健康值。该投影只用于聚合“每周有帮助复用次数”与护栏结果，不参与搜索、Memory 编译或 Agent ContextPack，因此不会成为删除后内容复活的第二索引。

## 场景、lineage 与结果记录

每次 attempt 都先记录 trigger intent 和范围；所用 Event/Memory 及 Memory→source Event lineage 仅以本次 attempt 加盐摘要持久化。结果可记录 `useful`、`not_useful`、`wrong_memory`、`important_miss`、`outdated`、`permission_denied`、`deletion_failure`、`recovery_failure`、`restricted_egress_blocked`，并可附 `revised`、`hidden` 或 `deleted` 用户动作。一个 attempt 只能追加一个 outcome，早于 attempt 的 outcome 拒绝。

这满足后续真实 Pilot 的可计算入口，但不构成真实结果。当前 repository/smoke 使用受控本机夹具验证行为；“每周有帮助复用次数”、错记忆率、重要漏失率、修订率、打扰率和删除/恢复失败率必须由正式参与者与真实触发面产生后才能用于产品判定。

## 未关闭 Gate

- 双端四类复用已进入生产 Search 触发面，Android AVD 与本地 iOS build/smoke 已覆盖仓库内可执行证据；iOS 新 UI 仍需完整 Xcode/XCUITest/截图，双端仍没有物理设备或真实用户证据，不能写成真实用户已经可用。
- 当前没有 Project 实体、Meeting/Contact 权限与语义模型。项目续接只能使用显式关键词；会前上下文只能使用用户选择的关键词/日期，不得推断项目、参会者或议程。
- Agent Local Node 仍只允许 frozen `create_event`。真实 Agent 读取需要共享协议、ContextPack manifest、exact Grant、撤权/过期和真实宿主验证，不能由本切片私自扩权。
- iOS 新 UI 的 XCTest、进程终止、物理设备与 VoiceOver，以及 Android 物理设备、OEM、真实 TalkBack 和 UI 性能仍未执行；AVD、静态门和 Swift smoke 不能关闭这些 Gate。
- T0 8 人 × 7 天 Pilot 尚未开始。真实 helpful、wrong memory、important miss、revision/hide/delete、prompt burden、permission denial、recovery/deletion failure、Restricted egress 和有效成本仍无真实分母。
- Source/Raw/摘要/索引/ContextPack 与 peer 的完整删除传播、分布式权威水位和物理删除证明继续属于 DEL-01/SYNC-01。

## 判定

`P0-LOCAL-REUSE-MOBILE-06` 关闭了仓库内“四类复用没有共同生产 API、复核与解析存在窗口、双端缺少克制且可达的用户入口、结果没有内容安全持久入口”的缺口，当前结论为 `conditional_pass`。不得将本报告扩写为 iOS 新 Xcode 已签收、真实用户 helpful、Agent recall、物理设备、生产删除传播或封闭 Beta 已通过。
