# M23 配对与连接生命周期验证（2026-07-18）

- Verdict：`conditional_pass`
- Scope：iOS Local Node pairing material strict parser、Android/iOS connector disconnect contract、Android 设置页断开状态清理顺序、既有 Swift→Android AVD 真实传输子门。
- Environment：macOS Command Line Tools；Swift 6.0；Android JDK 17、SDK 36、API 36 16 KB arm64 AVD。
- Limitation：当前没有完整 Xcode/XCTest runtime、iOS Simulator、iOS/Android 物理设备；二维码相机、账户 registry、进程重启后的真实 client reconnect 仍未证明。

## 结果

| Gate | 结果 | 证据 |
|---|---|---|
| iOS pairing parser | pass | `AgentLocalNodePairingMaterial.parse` 先运行 duplicate-key/JSON grammar scanner，再进入 Foundation object；Shared Smoke 覆盖合法 round-trip 与重复 `channel_protocol` 拒绝 |
| iOS connector lifecycle | pass（当前工具链） | `AgentExperienceConnector.disconnect` 已纳入协议；Bonjour connector 的 active client registry 在断开时移除并关闭 actor；AppModel 断开时清除展示状态并触发底层关闭 |
| Android connector lifecycle | pass（当前工具链） | `PairingExperienceConnector.disconnect` 已纳入协议；设置页在清除 `PairingExperienceStore` 前通知 connector；Debug 与 Release 实现均编译通过 |
| Android UI smoke | pass（既有 AVD 证据） | 三入口→授权确认→体验连接成功→断开→连接入口恢复，保持 `simulated` 标识与不联网文案 |
| Swift→Android Local Node | pass（跨端子门） | Swift Network.framework client → TLS 1.3/certificate pin/HMAC → Grant-bound `create_event` → Android Today 可见；秘密、ADB forward、临时 Swift 构建均清理 |
| QR/account/device | 待补 | 需要 shared QR envelope、相机扫描、account Grant registry、后台/旋转与物理设备/无障碍证据；真实 client credential 尚未安全持久化 |
| 进程重启状态真相 | pass（当前工具链） | iOS/Android store load 只恢复 `simulated` 展示状态；非模拟连接元数据在进程重启加载时清除，不会被显示为活跃传输 |

## 结论

M23 的输入拒绝、断开生命周期和进程重启状态真相已收口；这只证明当前代码与 AVD/Smoke 层行为，不把“已保存连接元数据”升级成进程重启后仍有活跃 session，也不把手动复制 JSON/secret 升级成二维码或账户设备功能。
